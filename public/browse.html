Browser backend not available

The Tuffs browser needs the Node backend running on this host (it serves the Scramjet client and the Wisp proxy backend). Start it with npm start and reload this page. If you are hosting static files only, the arcade works but this tab cannot.

The address bar, back/forward and reload controls you see here belong to your portal — they are not a real browser's chrome, and this tool does not make you anonymous or untraceable.

Pages load through the Scramjet client on your portal's own backend. Some sites (heavy CAPTCHAs, strict logins, DRM video) will not work — that is a limitation of the approach, not a bug in your setup. Nothing you browse here is recorded by the portal.
